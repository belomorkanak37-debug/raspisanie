Как получить ключ
  1. Откройте github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выберите репозиторий с приложением.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Срок действия — до года (потом создадите новый ключ так же).
  5. Нажмите Generate token, скопируйте ключ и вставьте сюда.

Ключ хранится только в этом браузере и отправляется только в GitHub.
