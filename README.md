# Расписание

Веб-приложение для телефона: человек вводит фамилию и видит все свои спектакли, репетиции и вводы.
Работает на бесплатном GitHub Pages, сервер не нужен.

- `index.html` — приложение для всех (поиск по фамилии, закрепление, список с прошлыми днями, календарь, итоги, калькулятор, работа без интернета).
- `admin.html` — страница для загрузки новых PDF и добавления отдельных событий (ссылки на неё в приложении нет).
- `data/` — опубликованные недели, исходные PDF и календари. Эту папку заполняет админ-страница.

## Как выложить в интернет (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Создайте репозиторий: кнопка **New** → имя, например `raspisanie` → **Public** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**)
   и перетащите **всё содержимое** папки `расписание` (файлы и папки `css`, `data`, `icons`, `js`). Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый: если он не загрузился, создайте через **Add file → Create new file** пустой файл с именем `.nojekyll`.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/raspisanie/`.
   Эту ссылку и рассылаете коллегам.

## Ключ для публикации (один раз)

1. Откройте [Fine-grained tokens → Generate new token](https://github.com/settings/personal-access-tokens/new).
2. **Repository access** → Only select repositories → `raspisanie`.
3. **Permissions → Repository permissions → Contents** → **Read and write**.
4. **Generate token** и скопируйте ключ.
5. Откройте `https://ВАШ-ЛОГИН.github.io/raspisanie/admin.html`, впишите логин, репозиторий и ключ → **Подключить**.

Ключ хранится только в вашем браузере. Никому его не пересылайте. Когда срок действия закончится, создайте новый так же.

## Новое расписание

1. Откройте `admin.html` → **Выберите PDF**.
2. Проверьте, что распознано: фамилии под каждым событием показаны так, как их увидит приложение.
   Если что-то не так, нажмите на событие и исправьте.
3. **Опубликовать**. Через 1–2 минуты расписание появится у всех.

Если загрузить исправленную версию уже опубликованной недели, она заменит старую, а у людей изменения
в их расписании подсветятся («изменено», «новое», «отменено»).

## Отдельное событие без PDF

1. Откройте `admin.html` → **Отдельное событие**, выберите дату → **Добавить событие**.
2. Заполните название, время, фамилии (с заглавной буквы, через запятую или по строкам), место / сцену и при необходимости звук, свет. Можно выбрать показ всем или пометку дня.
3. **Сохранить**, проверьте неделю → **Опубликовать**. Событие появится в приложении и персональных календарях.

Если на выбранную дату уже есть расписание, событие добавится к нему. Если расписания ещё нет, будет создана неделя без PDF. События, добавленные вручную, сохраняются при загрузке исправленного PDF; совпадающие записи не дублируются.

Кнопка **Изменить** у опубликованной недели открывает её события для добавления, исправления или удаления без повторной загрузки PDF.

## Как пользоваться (для коллег)

- Откройте ссылку, введите фамилию и нажмите **Закрепить**: дальше приложение будет открываться сразу на вашем расписании.
- Добавьте на экран «Домой»: iPhone — «Поделиться» → «На экран „Домой“», Android — меню браузера → «Добавить на главный экран».
- **В календарь телефона** — подписка, которая сама обновляется при каждом новом расписании.
- Нажмите на событие, чтобы увидеть полный состав и открыть оригинал PDF.
- **Календарь → выберите день → Добавить личное дело** — дата, название, начало / окончание, место и заметка. Без времени дело показывается на весь день. Кнопка **Изменить** открывает сохранённое дело для исправления или удаления. Можно перейти к любому месяцу, даже если театральное расписание ещё не опубликовано.
- **Список → Показать прошлые дни** — раскрывает прошедшие театральные и личные занятости над текущим расписанием. Кнопка «Показать ещё прошлые дни» загружает предыдущие недели.
- **Итоги** — приблизительный подсчёт по фамилии за выбранный месяц: спектакли и превышение нормы 8, бэбики, дни в трёх ролях на вводах, выездные показы. В шапке есть предупреждение о приблизительности расчётов.
- **Калькулятор** — введите оклад до налога и выберите месяц. Результат показывает оклад, каждую доплату, налог 13% и приблизительную сумму на руки; расчёт можно раскрыть по датам. Оклад хранится только в этом браузере, отдельно для каждой фамилии.

В итогах учтены все опубликованные даты месяца, включая будущие. Каждый личный показ считается отдельно;
«Собачка» и «Первый снег малыша» — бэбики: каждый входит в общее количество как 1 и отдельно отмечается в строке «Бэбиков».
«Теремок» для Баранова и Носова считается как 0,5, для остальных — как 1.
Выездные спектакли считаются отдельной графой и не входят в количество спектаклей для нормы 8. Отъезд без спектакля не считается показом.
Вводы считаются по уникальным дням для каждой указанной в составе роли. Участия с «?» и варианты через `/` показаны отдельно.
Отменённые события из прошлой версии расписания в итоги не входят. Если месяц загружен не целиком, раздел сообщает, сколько дней доступно.
Подсчёт работает и для прежних расписаний, и для новых PDF и событий из админки; для проверки можно раскрыть список учтённых дат.

В калькуляторе первые 8 спектаклей по датам и времени входят в норму без доплаты. Затем обычный показ даёт 5% оклада, бэбик — только 3%; бэбик внутри нормы надбавки не даёт. Доли спектакля сверх нормы оплачиваются пропорционально (0,5 обычного показа — 2,5%).
Выезды, гастроли и фестивали: первый личный показ каждого дня — 6%, второй и каждый следующий — 5%, независимо от нормы в театре.
Каждый день ввода: вводящийся — 6%, вводящий — 3%, актёр на вводе — 4%. В расчёт берутся только участия без вопроса и альтернативного состава. С суммы оклада и доплат удерживается 13%.
Классификация бэбиков и исключение для «Теремка» встроены в `eventAccounting`; при загрузке PDF и создании события признаки сохраняются в JSON, а для старых расписаний пересчитываются при просмотре.
Проверка правил подсчёта и доплат: `node tests/accounting.mjs`.

Расписание доступно всем, у кого есть ссылка.

Личные дела сохраняются только в браузере, где они добавлены, отдельно для каждой фамилии.
Они отображаются в «Календаре» и «Списке» по дате и времени; прошедшие дела доступны через «Показать прошлые дни».
Дела на даты без опубликованного театрального расписания также видны в списке.
На других телефонах и в других браузерах они не видны; на общем устройстве они доступны тому, кто откроет ту же фамилию в том же браузере.
Личные дела не отправляются в репозиторий, не входят в «Итоги» и общую подписку календаря. Они работают без сети;
при очистке данных браузера удаляются. Синхронизации между устройствами и аккаунтов пока нет.
